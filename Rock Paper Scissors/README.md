# Rock Paper Scissors Game 🎮

A simple Rock Paper Scissors game built with Python.

The player competes against the computer, which randomly selects rock, paper, or scissors. The program compares both choices, determines the winner, and keeps track of the score.

## 🚀 Features

* Player vs Computer gameplay
* Random computer choice generation
* Score tracking system
* Input validation for incorrect choices
* Option to play multiple rounds

While building this project, I practiced:

* Conditional statements (`if`, `elif`, `else`)
* `while` loops
* The `random` module
* `break` and `continue`
* Basic program logic and debugging

## ▶️ How to Run

1. Make sure Python is installed on your computer.

2. Clone this repository:

```bash
git clone https://github.com/Sammy5code/AI-Learning.git
```

3. Navigate to the project folder:

```bash
cd Rock-Paper-Scissors
```

4. Run the program:

```bash
python3 rock_paper_scissors.py
```
